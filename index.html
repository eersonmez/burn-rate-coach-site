Private by design

Your quota stays in Chrome.

While the Codex usage page is open on Overview or Analytics, Codex Limit Coach passively observes the page's own successful quota parse. The packaged bridge accesses only base and additional quota-group identity, used percentage, window duration, and reset timing; each additional name becomes an opaque stable identifier. The isolated script associates meters with native rows through numeric progress and compatible reset metadata, never translated labels or card order. Settings and bounded history remain in chrome.storage.local.

The bridge initiates no request, independently parses no response, inspects no credentials or unrelated account fields, and transmits no quota data. The sole extension API permission is storage. Content scripts match direct and SPA navigation on https://chatgpt.com/codex/* and https://chatgpt.com/settings/usage*; runtime capture is limited to the two Usage tabs or the legacy usage view, and coaching renders on Overview or that legacy view. There is no background context, backend, telemetry, advertising, remote code, or Codex Limit Coach account system.

Know the limits

A coach, not a guarantee.

  • Automatic history is processed only while Usage Overview or the legacy usage view is visible; hidden tabs record no scheduled cadence samples.
  • Percentage points are not tasks, tokens, messages, or minutes.
  • Projections are model-based estimates, not guarantees, and are not empirically calibrated on real usage histories.
  • Quota collection works across Codex interface languages; the coach interface supports English, Turkish, Hindi, Spanish, Arabic, French, German, Japanese, and Portuguese (Brazil and Portugal).
